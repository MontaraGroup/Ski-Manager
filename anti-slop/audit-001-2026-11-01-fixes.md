# antislop audit 001: fix report

Date: 2026-11-01
Approved items: 1-9, 12, 13, 18, 19, 20 (from `audit-001-2026-11-01.md`). Items 10, 11, 14, 15, 16 and 17 are untouched.
Branch: `fix/antislop-audit-001`. Tested on staging; not on production.

## What changed

1. **Light theme home page.**
   - Cause: the layout's inline `:root { color-scheme: dark light }` overrode each theme's own `color-scheme`, and nothing set the page text color. The text fell back to the browser's dark-scheme default (white), even in the light theme.
   - Fix: removed that line and set `body { color: var(--color-base-content) }` in `input.css`.

2. **Primary buttons.**
   - New `--color-primary-fill` (`--pf`): `oklch(52% 0.18 245)` in the dark theme, which gives white text 4.83:1. The light theme keeps `--p`.
   - Where it's used:
     - `.btn-primary`, active menu items, `.btn-active` and the skip link.
     - The 3 views that put `bg-primary` behind `text-primary-content`.
   - `--p` itself is unchanged, so blue text on dark panels keeps 4.9:1 or more.
   - Primary button hover now darkens instead of lightening, so the label keeps its contrast.

3. **Muted text.**
   - Text opacity:
     - `text-base-content/40`, `/50` and `/60` become `/70` on text elements: 832 uses in 82 views. Icons (`<i>`) are unchanged.
     - Inline `color-mix(... base-content N%)` text colors under 70% become 70%: 39 places.
   - Theme colors:
     - **Light theme:** the status colors (info, success, warning, error) and the accent moved to L 48-52%, with white content text, so green cash and orange warnings read at 4.5:1 or more on the light panels.
     - **Dark theme:** the secondary purple moved to L 68% with dark content text (text 5.7:1, button 6.2:1).
   - `terrain_parks/index.php` is left alone because the terrain-parks branch rewrites it.

4. **Hover.**
   - The "REMOVE ALL HOVER EFFECTS" block now keeps transitions and lift effects off. Links and cards get their hover back:
     - Text links underline on hover (2px).
     - Card links get a primary border.
   - Buttons keep their fill change.

5. **Endless animations.** Removed `animate-pulse` and `animate-ping` from:
   - the notifications bell
   - the tournament Live and Active badges
   - the mobile dock bonus dot
   - the roadmap "in progress" dot

   Each dot or badge stays, now static, where it marks a real state.

6. **Night skiing.** The server-clock "active now" text and the LIVE badge are replaced with what the game does: switched-on lights run every game day, and the nightly tick charges their energy and wear.

7. **Tap targets.**
   - On touch screens (`pointer: coarse`) these get a 44px minimum:
     - every `.btn` size, icon buttons, menu rows
     - footer links, the logo links
     - the standalone links on the home page
   - Mouse layouts keep their compact sizes.
   - The phone navbar padding was tightened so brand, theme toggle, Log in and Play free still fit at 375px.

8. **Em dashes.**
   - Replaced in views, tooltips, flash messages, notifications, the activity log, event and upgrade descriptions, and the legal pages.
   - Empty-value markers now use an en dash.
   - Migration `2026-11-01-120000_EventTextWithoutEmDash` rewrites the two event descriptions already stored in `special_events`.
   - Left as is:
     - the developer error page
     - CLI output
     - the admin contact email

9. **Accessibility.**
   - The Sentry bundle is now `defer`, and its init runs from the bundle's own `onload`. With Cloudflare Rocket Loader, another Sentry script can reach `window.Sentry` first, so the onload is the reliable moment.
   - The back-to-top button has `aria-label` and `type="button"`, and is 44px.
   - The Discord and GitHub icon links have `aria-label`, with their icons `aria-hidden`.
   - The navbar is wrapped in a `<header>` landmark (the sticky positioning moved to the header).

12. **Toast glow.** Removed. Warning toasts keep a red border; the others use the plain border.

13. **Emoji.**
   - Removed from:
     - the Demo and Alliance flash messages and notifications
     - the map editor's "Snapped" pill
     - the admin broadcast icon list
   - Leaderboard medals are Font Awesome medal icons now: gold, silver, bronze, hidden from screen readers since the rank number is printed beside them.
   - Map difficulty options use the trail-sign shapes (● ■ ◆ ◆◆) in both lists.

18. Cash Injection says "100,000 €".

19. The home page title is "Free Online Ski Resort Tycoon Game - Ski Manager".

20. Deleted `app/Views/dashboard/index.bak.php`.
